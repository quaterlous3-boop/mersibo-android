# Android Studio Project: Мерсибо Игры (Mersibo Games)

Полноценное автономное Android-приложение для планшетов и телефонов с обучающими играми Мерсибо.

## Особенности сборки
- **100% Автономность**: В APK уже зашиты 10 популярных разноплановых игр (сцены, озвучка, бандлы) + движок Unity WebGL. Приложение работает полностью офлайн без интернета.
- **Встроенный локальный микро-сервер (`MersiboLocalServer`)**:
  - Обеспечивает работу Unity WebAssembly и IndexedDB через локальный интерфейс `127.0.0.1:8080`.
  - Обслуживает базовые игры прямо из APK (`assets/www/`).
  - Поддерживает **докачивание остальных игр по требованию**: если запущена игра не из базовых 10 и есть Wi-Fi — сервер скачивает её файлы с серверов Мерсибо и навсегда кэширует в память устройства (`files/mersibo_storage`), после чего она работает офлайн.
- **Полноэкранный режим**: Приложение фиксировано в альбомной ориентации (`sensorLandscape`) с скрытием системных панелей.

## Как открыть и собрать в Android Studio:
1. Запустите **Android Studio**.
2. Выберите **Open** и укажите эту папку: `/home/kostya/Рабочий стол/mersibo_android`.
3. Дождитесь завершения синхронизации Gradle.
4. В меню выберите: **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
5. Готовый файл `.apk` появится в `app/build/outputs/apk/debug/app-debug.apk`.
6. Установите его на любой планшет или телефон Android (версия Android 7.0 и новее).
